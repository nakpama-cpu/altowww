Apply the requested changes to the shared invoice template used by the portal, then regenerate Mr Huw Owen's paid invoice with the same layout.

## Changes

1. **A4, no extra padding** — page stays A4 (595.28 x 841.89pt); the header band and copper footer bar run edge to edge and the outer margin is tightened so content sits flush to a slim margin with no dead space around it.
2. **Payment reference = invoice number** — the reference shown in the meta block, the bank-transfer block and the "please quote" line all use the invoice number itself instead of the derived `AW260052` form. New invoices store the invoice number as the payment reference.
3. **Unit price and amount show both prices** — where a discount applies, the unit price column shows the full list price struck through above the discounted unit price, and the amount column shows the full line amount above the discounted amount, so the saving is visible on the line itself.
4. **Remove the VAT sentence** — the "Cask whisky held in bonded warehouse is not subject to VAT while under bond." line is deleted.
